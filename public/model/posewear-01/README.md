## 重建默认输入

在仓库根目录运行 `python scripts/build-model-front.py`；加 `--check` 仅重建到内存并与文件逐字节比较。离线工具使用 Pillow（本次 12.1.1），不属于 Web 运行时依赖。换源须先复核 SHA-256 和取样坐标；输出字节改变时，默认图片 URL 的 `v` 取新文件 SHA-256 前 12 位。

以左上角为原点：保留 R5 三视图的 `x=[0,376)、y=[0,1516)`，不缩放、不插值，直接平移至 `(322,20)`。只有底部 20 行空地没有使用；头发、双手、赤脚及原接触影均包含在保留区。

两翼底色分别取自正面栏两侧的 16 像素空背景，平滑逐行色调，再叠回同侧空背景的细纹理；接缝镜像过渡只画在新增区域。顶部 20 行镜像自无发丝的棚顶。只使用正面栏，不取侧面、背面或 `face.png`，不重绘人物。这是输入画布，不改变成片构图或身体比例契约。
