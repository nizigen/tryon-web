# 前端设计参考：flyne.ai/cn（实测 2025-11-22）

来源：`https://flyne.ai/cn/create/`、`https://flyne.ai/cn/ai-image-generator/`，浏览器实测截图：
`docs/evidence/flyne-create.png`、`docs/evidence/flyne-image-generator.png`、`docs/evidence/flyne-home.png`。

## 1. 整体气质
- **深色 AI 工作台**：近黑底 + 低对比描边 + 一个高饱和紫色作为唯一强调色，靠留白与圆角营造「专业工具」感，不用阴影堆叠。
- 布局：左侧固定导航（分组可折叠）＋ 主工作区；主工作区上半是「提示词卡片」，卡片内底部一排胶囊控件（类型／模式／模型／分辨率／比例／数量）＋ 右下角主行动按钮。
- 结果区在主区下方，用分段胶囊切换（视频 / 图片 / 音乐）。

## 2. 设计令牌（从 computed style 实测）
| 令牌 | 值 |
| --- | --- |
| 字体栈 | `"PingFang SC", arial, tahoma, "Hiragino Sans GB", "Microsoft YaHei", sans-serif` |
| 基础字号 | 16px；控件文字 14px；辅助说明 12px |
| 页面底色 | 近黑 `#0a0a0a`（body 实测 `rgb(0,0,0)`，面板略亮 `#111`/`#161616`） |
| 主文字 | `#ffffff`；次要 `rgba(255,255,255,.55)`；禁用 `rgba(255,255,255,.4)` |
| 描边 | `1px solid rgba(255,255,255,.10)`（hover 提亮到 `.18`） |
| 圆角 | 卡片 `20px`；面板/大块 `16px`；小控件 `8px`；**胶囊控件 `999px`** |
| 控件高度 | 导航按钮 40px；胶囊下拉 36–40px；主按钮 48px |
| 强调色 | 紫 `#7c3aed → #a855f7` 渐变（按钮、选中态、进度）；光晕 `rgba(124,58,237,.35)` |
| 动效 | 150–200ms ease；hover 只做背景/描边提亮，不做位移 |

## 3. 组件形态
- **胶囊下拉（本项目的核心控件）**：`display:inline-flex; gap:6px; align-items:center; padding:0 14px; height:36–40px; border-radius:999px; border:1px solid rgba(255,255,255,.10); background:#161616;`hover 背景 `#1f1f1f`；右侧 chevron 12px；展开时同一胶囊描边变紫、下方浮层与胶囊同宽、同一圆角语言（`border-radius:14px`）、底色 `#1a1a1a`、`box-shadow:0 12px 32px rgba(0,0,0,.5)`。
  - **一致性铁律**（用户明确要求）：下拉未展开与展开后，字体、字号、行高、左右内边距、高度、圆角必须一致；选中项左侧加紫色对勾，未选中项不加任何占位符，保证列表项左边缘与触发器文字左边缘对齐。
- **主按钮**：胶囊，高 48px，紫渐变底 + 白字，右侧可带额度数字；禁用态降饱和度到 40%。
- **提示词卡片**：`border-radius:20px`，`1px` 描边，内边距 24px，含占位文案「请输入提示词」与左上小图标按钮（上传参考图）。
- **左侧导航**：分组标题 12px 灰字 + 折叠箭头；条目 40px 高、8px 圆角、选中时背景 `rgba(124,58,237,.14)` + 紫字。

## 4. 本项目如何映射（虚拟试穿工作台）
| flyne 元素 | 本项目对应 |
| --- | --- |
| 左侧导航 | 橱窗 / 试穿工作台 / 我的衣橱 / 设置 |
| 提示词卡片 | 「搭配面板」：人物照片 + 各穿搭格子（上衣/外套/下装/连裤袜/鞋/配饰） |
| 胶囊控件行 | 每个穿搭格子一个胶囊选择器（品类）+ 一个胶囊（子类） |
| 主行动按钮 | 「开始试穿」（演示模式不显示价格/额度） |
| 结果分段切换 | 「原图 / 结果 / 对比」分段胶囊 + 下载 |

## 5. 硬性要求（验收口径）
1. 深色主题在 1440 / 1024 / 390 三档都不出现横向滚动。
2. 所有下拉：默认态与展开态样式一致（字体/高度/内边距/圆角），未选择时触发器显示占位灰字而非空白。
3. 主按钮 48px 高、可键盘聚焦（`:focus-visible` 有紫色描边环）。
4. 触控目标 ≥ 44px（移动端）。
5. 不使用除紫色强调色以外的饱和色；不使用多层阴影。
