## 共同输入与约束

- 场景：单人、中文、静态图片虚拟试衣工作台，最常用的素材上传、类别、引擎与试穿入口集中首屏。
- 比较基准：桌面 1440 × 900，窄屏目标 375 × 812；使用系统无衬线字体，无外部字体或框架。
- 范围：人物照片、单件衣物、上装/下装/连衣裙、Decart/OpenAI 兼容选项、原图/结果对照、结果下载入口、当前会话历史空状态。
- 资产：没有用户真实照片、官方品牌标识或已生成结果。不借用原插件资产；上传区和结果均为诚实空状态。Decart/OpenAI 仅为文字接口名称，无品牌视觉复刻或能力声明。
- 原生浏览器能力已足够：file input + URL.createObjectURL + CSS Grid + query 参数变体 + iframe 缩放，无依赖安装。
- 预览上传上限 20 MiB 是防止展示页大文件阻塞的局部限制，不作为未来生产接口的契约；生产界限由项目规范单独确定。

- 类别与引擎可真实切换选中状态；对比按钮可真实切换原图、结果和并排布局。
- 上传人物照片会出现在原图框；结果框始终没有伪造图。
- 试穿、下载和历史按钮只显示可访问的提示，不调用 API、不产生任务、不下载原图冒充结果。
- 刷新清空素材和状态；离开页面释放对象 URL。
- 三个备选以 `?variant=alt` 展示真实布局变化，非截图换色。
